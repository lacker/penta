# cEDH seed decklists

These 119 tournament lists seed the cEDH deck selection with examples of
competitive decks from [Nacional de cEDH 100K @ WolfCon 2026](https://edhtop16.com/tournament/nacional-de-cedh-100k-1).
Each YAML records its source and keeps commanders separate from the main deck.

The lists can evolve with the rest of the deck catalog. Including a deck does
not imply complete card support or enforce format legality. See
[Commander foundation](../../docs/commander.md).
