# Duel Commander seed decklists

These eight published top-eight lists from [DC – CommandFest Italy 2026 in Bologna](https://mtgtop8.com/event?e=90544&f=EDH) seed the format. The event had 69 players and took place on 2026-09-05.

Each YAML retains its source link and separates commanders from the main deck.
The source export labels commanders as “Sideboard”; these lists have no actual
sideboard, so their YAML omits that section. The lists can evolve with the deck
catalog. Catalog inclusion does not imply complete card support or legality.

See [Commander formats](../../docs/commander.md) for gameplay and deferred
construction checks.
